About The Project

Fake News Detector built for clear analysis, practical use, and readable results

This project checks news content and estimates whether an article looks like trusted reporting or follows misleading patterns. The system combines BERT-based language understanding, structured text preparation, and a clear confidence score to give users a fast and useful result.

BERT-based classification URL + text input support Confidence-driven result flow

Core Goal

Identify whether a news story feels real or fake.

Main Stack

Django frontend-backend flow with a BERT classifier.

Output Style

Prediction, confidence, article preview, and reasoning.

How It Works

Detection workflow

This page does not only introduce the model. It also explains how the result is created. The full process is shown below.

01

Input collection

The user pastes article text or provides a direct URL. The system tries to collect readable content.

02

Text preparation

The news content is cleaned, extra fragments are removed, and the text is prepared for the model.

03

Model inference

The BERT classifier studies language cues, tone, structure, and wording strength to make a prediction.

04

Readable output

The final result page shows confidence, an article preview, and analysis insights in a clear format.

Training Data

Dataset foundation

The model was trained with Kaggle datasets `Fake.csv` and `True.csv`, which contain labeled news headlines and article text.

Model Focus

Language pattern reading

The system studies sensational wording, consistency, writing style, and reporting-like structure to build a signal-based understanding.

Result Logic

Confidence-driven output

The final page shows more than a label. It also shows a confidence score and helpful analysis details.

What The System Looks For

Signals used in analysis

The prediction is not based on a headline alone. The detector combines multiple text signals.

Headline tone

The system checks whether the headline sounds like neutral reporting or uses exaggerated, attention-grabbing language.

Article structure

It studies content flow, sentence quality, and detail consistency to understand whether the article is coherent.

Language intensity

Overdramatic phrases, repeated emphasis, and suspicious wording are important signals for the detector.

Confidence response

A confidence score is shown with the prediction so the user can understand how strong the result is.

Best Use

Tips for better results

A full paragraph or full article body gives the model more context, so the result is usually better.
When using URL extraction, it is best to provide the original article link and avoid social share redirects.
It is still recommended to verify the story with multiple trusted sources before making a final decision.

Responsible Use

Use this as decision support

Predictions are probabilistic. The system is a helpful indicator, but it is not a replacement for final fact-checking.
For political, medical, legal, or other sensitive stories, manual verification and source cross-checking are very important.
In low-confidence cases, it is better to analyze the article again or provide the full content.
