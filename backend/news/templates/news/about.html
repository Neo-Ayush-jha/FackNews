About The Project

Fake News Detector built for clear analysis, practical use, and readable results

Yeh project news content ko analyze karke estimate karta hai ki article verified reporting jaisa lag raha hai ya misleading patterns follow kar raha hai. System BERT-based language understanding, structured preprocessing, aur readable confidence output ko combine karta hai taake user ko fast aur useful result mil sake.

BERT-based classification URL + text input support Confidence-driven result flow

Core Goal

Identify whether a news story feels real or fake.

Main Stack

Django frontend-backend flow with a BERT classifier.

Output Style

Prediction, confidence, article preview, and reasoning.

How It Works

Detection workflow

About page ka purpose sirf model introduce karna nahi hai, balki user ko samjhana bhi hai ke result generate kaise hota hai. Neeche complete flow diya gaya hai.

01

Input collection

User article text paste karta hai ya direct URL deta hai. System readable content ko capture karne ki koshish karta hai.

02

Text preparation

News content clean hota hai, unnecessary fragments remove hote hain, aur model-ready text structure banaya jata hai.

03

Model inference

BERT classifier language cues, tone, structure, aur wording intensity ko evaluate karke prediction banata hai.

04

Readable output

Final result page confidence, article preview, aur analysis insights ke saath clear human-readable format me show hota hai.

Team Contributions

Project roles

Team structure ko yahan clearly mention kiya gaya hai taake project responsibility aur implementation areas samajh aayein.

Ayush ne backend ka kaam kiya hai, including API flow, server-side prediction logic, request handling, response formatting, aur system integration.

Anshu

Neo ne datamodel par kaam kiya hai, including prediction record structure, data storage planning, field organization, aur result persistence flow.

Training Data

Dataset foundation

Model training ke liye Kaggle ke `Fake.csv` aur `True.csv` datasets use kiye gaye, jisme labeled news headlines aur article text available hai.

Model Focus

Language pattern reading

System sensational wording, consistency, phrasing style, aur reporting-like structure ko evaluate karke signal-based understanding develop karta hai.

Result Logic

Confidence-driven output

Final page me sirf label nahi dikhaya jata, balki confidence score aur supporting analysis details bhi show ki jati hain.

What The System Looks For

Signals used in analysis

Prediction sirf ek headline dekh kar nahi hoti. Detector multiple textual indicators ko combine karta hai.

Headline tone

System dekhta hai ke headline neutral reporting jaisi hai ya exaggerated attention-grabbing style me likhi gayi hai.

Article structure

Content flow, sentence quality, aur detail consistency ko evaluate kiya jata hai taake article coherence samajh aaye.

Language intensity

Overdramatic phrases, repetitive emphasis, aur suspicious wording detector ke liye important signals hote hain.

Confidence response

Prediction ke saath confidence diya jata hai taake user samajh sake ke detector result kitni strength ke saath de raha hai.

Best Use

Tips for better results

Full paragraph ya full article body dene se model ko zyada context milta hai, isliye result better hota hai.
URL extraction use karte waqt original article link dena best hai, social share redirects se bachna chahiye.
Final decision lene se pehle multiple trusted sources se verify karna still recommended hai.

Responsible Use

Use this as decision support

Predictions probabilistic hoti hain. System helpful indicator hai, lekin final truth checker replacement nahi hai.
Political, medical, legal, ya sensitive stories ke case me manual verification aur source cross-check zaroor karein.
Low confidence cases me article ko dubara analyze karna ya full content provide karna better practice hoti hai.
