# admin.py Viva Questions

## 1. admin.py ka use kya hai?
Answer: Model ko admin panel me manage karna.

## 2. PredictionAdmin kyun bana?
Answer: List ko readable banane ke liye.

## 3. list_display me kya hai?
Answer: id, user, result, confidence, created_at.

## 4. list_filter ka fayda kya hai?
Answer: Records filter karne ke liye.

## 5. search_fields kya karta hai?
Answer: Text aur user info search karne ke liye.

## 6. ordering kyun set hai?
Answer: Latest record top par lane ke liye.
