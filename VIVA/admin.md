# admin.py Viva Questions

## 1. admin.py ka purpose kya hai?
Answer: Prediction model ko Django admin panel me manage karne ke liye.

## 2. PredictionAdmin kyun banaya gaya hai?
Answer: Admin list ko readable aur searchable banane ke liye.

## 3. list_display me kya dikhaya gaya hai?
Answer: id, user, result, confidence, aur created_at.

## 4. list_filter ka use kya hai?
Answer: Result, created_at, aur user ke basis par filter karne ke liye.

## 5. search_fields ka fayda kya hai?
Answer: Admin me text, username, aur email search karne ke liye.

## 6. ordering kyun set ki gayi hai?
Answer: Latest predictions sabse upar dikhane ke liye.
