# apps.py Viva Questions

## 1. apps.py ka role kya hota hai?
Answer: Django app ki configuration define karna.

## 2. NewsConfig kya karta hai?
Answer: news app ka AppConfig define karta hai.

## 3. ready() method ka use kya hai?
Answer: App load hone ke baad extra startup logic chalane ke liye.

## 4. Model preload kyun kiya gaya hai?
Answer: Server start hone ke baad model ko background me warm up karne ke liye.

## 5. ENABLE_MODEL_PRELOAD ka use kya hai?
Answer: Preload ko on ya off karne ke liye environment control.

## 6. RUN_MAIN check kyun hota hai?
Answer: Django autoreloader me duplicate preload avoid karne ke liye.

## 7. load_model_background ka use kya hai?
Answer: Model ko background thread me load karne ke liye.
