# auth.html Viva Questions

## 1. auth page ka use kya hai?
Answer: Login aur register dono handle karna.

## 2. loginTab aur registerTab kya karte hain?
Answer: Forms ke beech switch karte hain.

## 3. profilePanel kab dikhaya jata hai?
Answer: Jab user already logged in ho.

## 4. login form me kaun se fields hain?
Answer: Email aur password.

## 5. register form me kaun se fields hain?
Answer: Full name, email, aur password.

## 6. postJson helper ka use kya hai?
Answer: JSON body ke saath API request bhejne ke liye.

## 7. login ke baad kya hota hai?
Answer: User ko home page par redirect kiya jata hai.

## 8. register ke baad kya hota hai?
Answer: Account create hota hai, phir auto login hota hai.

## 9. profileLogout ka role kya hai?
Answer: User ko logout karna.
