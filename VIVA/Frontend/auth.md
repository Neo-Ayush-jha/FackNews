# auth.html Viva Questions

## 1. auth page ka use kya hai?
Answer: Login aur register.

## 2. loginTab aur registerTab kya karte hain?
Answer: Form switch karte hain.

## 3. profilePanel kab dikhata hai?
Answer: User login ho to.

## 4. Login fields kya hain?
Answer: Email aur password.

## 5. Register fields kya hain?
Answer: Name, email, password.

## 6. login ke baad kya hota hai?
Answer: Home par redirect.

## 7. register ke baad kya hota hai?
Answer: Account create aur login.

## 8. CSRF token kyun hai?
Answer: Security ke liye.
